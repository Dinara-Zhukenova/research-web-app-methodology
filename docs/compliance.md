# Соответствие критериям оценки

| № | Критерий | Реализация в проекте | Баллы |
|---|---|---|---:|
| 1 | Тема и seed-данные | IoT-освещение; 40 синтетических наблюдений двух режимов | 5 |
| 2 | Архитектура по слоям | `models.py`, `schemas.py`, `service.py`, `router.py` | 10 |
| 3 | API | CRUD, поиск по двум полям, фильтр, сортировка, пагинация, 404/422 | 15 |
| 4 | Модели и Alembic | SQLAlchemy-модель и первая миграция | 10 |
| 5 | Тесты и линтер | 10 тестов, pytest и Ruff в CI | 10 |
| 6 | Frontend | Список, поиск, карточка, создание, изменение, удаление | 15 |
| 7 | Ошибки и адаптивность | `error.tsx`, `not-found.tsx`, серверная валидация, мобильные CSS-правила | 5 |
| 8 | Docker Compose | PostgreSQL, backend и frontend запускаются одной командой | 10 |
| 9 | CI, Dependabot, секреты | Два workflow, Dependabot, `.env` исключён из Git | 10 |
| 10 | Документация | README, архитектура, ER-диаграмма, каталог скриншотов | 5 |
| 11 | Защита | В README дан порядок демонстрации и ключевые объекты показа | 5 |

Итого по обязательным критериям: **100 баллов** после успешного запуска проверок и добавления реальных скриншотов.

Перед сдачей необходимо:

1. заменить автора в `CITATION.cff`;
2. заменить `USERNAME/REPOSITORY` в значках README;
3. после запуска приложения добавить 2–4 реальные картинки в `docs/screenshots`;
4. разместить проект в публичном GitHub-репозитории;
5. показать зелёные GitHub Actions и записать видео 3–5 минут.
